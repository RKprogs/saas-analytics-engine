# Product Case Study

## Problem

SaaS companies need visibility into:

- User engagement
- Retention
- Churn risk
- Experiment performance

Most solutions require multiple tools.

This project demonstrates a unified intelligence platform.

---

## Dataset

Synthetic SaaS dataset:

- 500 users
- 10,000+ events
- 2,000+ clicks
- A/B experiment assignments

---

## Churn Prediction

Features:

- total_events
- days_since_last_event

Model:

Logistic Regression

Output:

Probability of churn for each user.

---

## Experiment Analysis

Experiment:

button_test

Variants:

- A
- B

Simulated result:

Variant A:
8% conversion

Variant B:
15% conversion

Statistical significance evaluated using z-test.

---

## Business Value

Product teams can:

- identify churn risk
- evaluate experiments
- track engagement
- analyze growth

using a single platform.
